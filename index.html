SOAP 病例產生（英文）

會依勾選內容自動產生英文 SOAP 病例，並列出最可能診斷、鑑別診斷、建議檢查與治療（僅供參考，仍需臨床判斷）
翻譯設定：Google Gemini API Key（免費，手動補充欄位如果打中文，會用這組 key 呼叫 Gemini 翻成醫學英文）

這組 key 只會存在你這台電腦的瀏覽器裡（localStorage），翻譯時會直接從瀏覽器送到 Google 的 API，不會經過任何中間伺服器。 key 可以到 aistudio.google.com 申請，免費、不需要信用卡。 如果不填 key，手動補充欄位的文字會照你打的原樣併入病例（不會自動翻譯）。
換一台電腦或換瀏覽器使用時，這組 key 不會自動同步過去，需要重新貼上一次。
